# **Sports for which odds are accessible through the Odds API**

A data set mapping Sports Events/League names to keys for end-user ease.

## Usage

``` r
data(toa_sports_keys)
```

## Format

A data frame with 5 variables:

key - Sport key group - Sport group (non-league description) title -
Sport title description - Sport description has_outrights - Whether the
sport or event has outright victories.
