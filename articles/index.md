# Articles

### All vignettes

- [Building a sports-odds pipeline with
  oddsapiR](https://oddsapiR.sportsdataverse.org/articles/building-an-odds-pipeline.md):

  Assembling a repeatable odds-collection pipeline with `oddsapiR` -
  scheduling pulls, storing line history, and tracking how a market
  moves toward close.

- [Getting started with
  oddsapiR](https://oddsapiR.sportsdataverse.org/articles/oddsapiR.md):

  Getting started with The Odds API in R - authenticating, listing
  available sports with
  [`toa_sports()`](https://oddsapiR.sportsdataverse.org/reference/toa_sports.md),
  and pulling current lines with
  [`toa_sports_odds()`](https://oddsapiR.sportsdataverse.org/reference/toa_sports_odds.md).
